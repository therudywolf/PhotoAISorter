# Third-Party Notices

Photo AI Sorter depends on third-party Python packages listed in `requirements.txt` and development-only packages listed in `requirements-dev.txt`.

Runtime dependencies:

- CustomTkinter
- Pillow
- Requests
- pillow-heif
- OpenCV Python headless
- ImageHash
- NumPy
- Send2Trash
- PyTorch
- open-clip-torch
- windnd (Windows only)

Development dependencies:

- pytest
- ruff

Licenses for these packages are provided by their upstream projects and by the installed wheel metadata in your Python environment.

FFmpeg is not committed to this repository. If you distribute a build that bundles `ffmpeg-runtime`, include the FFmpeg license notices and corresponding source information for the exact FFmpeg build you ship.
