# Как повысить точность сортировки (CLIP / гибрид)

CLIP хорошо отделяет **очень разные** классы. При **50–80 похожих** тегах без примеров ошибки нормальны — нужны эталоны, описания и VLM.

## 1. Эталоны (самый сильный эффект)

Папки `data/refs/<имя_тега>/` — 10–20 чётких фото **на каждый** важный личный тег (`iam`, `my_dog`, …).

Без эталонов CLIP опирается только на текст описания — для похожих категорий это слабо.

## 2. Описания тегов

В **Теги…** для каждого тега заполните поле описания: что именно должно попасть в папку, чем отличается от соседних тегов.

Пример:
- `iam` — «фото меня, мужчина 30 лет, борода»
- `human_real_sfw` — «другие люди, не я»

## 3. Настройки в GUI

| Параметр | Рекомендация |
|---------|----------------|
| Точность | **Ультра** |
| CLIP | **GPU** (не CPU-only PyTorch) |
| VLM fallback | **Включён** только если LM Studio с **хорошей** vision-моделью; иначе выключите — CLIP+эталоны часто точнее |
| Скачать веса CLIP | Один раз перед большим прогоном |

Сомнительные файлы (низкое сходство, маленький отрыв от 2-го места) уйдут в **review**. VLM вызывается только для явно слабых CLIP-оценок, а не для каждого `needs_review`.

## 3.1 Эталоны — как не испортить точность

- Кладите в `data/refs/<тег>/` только **типичные** фото этой папки (не «всё подряд»).
- **10–20** снимков достаточно; 100+ разных сцен размывают прототип.
- Не дублируйте одно лицо в `iam`, `iam_face`, `iam_body` одними и теми же файлами — теги начнут «перетягивать» чужие кадры.
- Если после добавления эталонов стало хуже — удалите слабые/старые снимки из папки refs и перезапустите сортировку (кеш CLIP пересчитается).

## 4. Меньше тегов = выше точность

Разбейте один огромный список на 2–3 набора и прогоните отдельно, либо удалите редкие/дублирующиеся теги.

## 5. Проверочный прогон

Включите **«Только отчёт»** на 200–500 файлах, посмотрите `manifest.jsonl` в `_review_runs/`, поправьте описания и эталоны, затем полный прогон.

## 6. Что делает движок (v7 strict)

- Softmax только среди **top‑K** похожих классов (не среди всех тегов сразу)
- Отказ от угадывания при **низком** сыром сходстве → `uncategorized` + review
- Учёт **отрыва** между 1-м и 2-м местом по cosine
- Эвристики **только по имени файла** (`screenshot`, `receipt`, `document`).
  Эвристики по соотношению сторон и яркости убраны: вертикальное фото с
  телефона имеет те же пропорции, что и скриншот, и из-за этого обычные
  фото уходили в `screenshot`/`document`.
- CLIP-промпты **только на английском** (модель OpenAI обучена на английском).

## 7. Проверка точности

Если в `data/refs/<тег>/` есть фото, запустите:

```bash
.venv/Scripts/python scripts/eval_accuracy.py
```

Скрипт делает leave-one-out по эталонам и печатает точность по каждому тегу —
так любое изменение настроек можно сверять числом, а не на глаз.
